Team culture
● Play fast — sprint to LOS, no dawdling ever
● Be physical — aggressive (legal) flag pursuit and blocking
● Celebrate together — same team TD celebration every score
● Blocking wins games — celebrate it as loudly as TDs
● Compete to win — effort and execution, not just participation
Quick rules reminder — 7/8
✓ 8v8, 2 coaches/side on field
✓ DL must engage OL first
✓ LBs 5 yds off LOS, no blitz
✓ QB can't sneak up the middle
✓ No fumbles — dead on drop
✓ Punt = 20 yds free
✓ Possessions start at 20
✓ Safety = flag in own end zone
✓ Rotate ALL ball carriers
✓ Down 8 in 2 min = clock stops
Rules reminder — 5/6 (Mount Prospect)
✓ 6v6, coaches on field
✓ No blocking (screening only)
✓ No blitz — defenders at LOS
✓ QB no run or delayed run
✓ No fumbles — dead on drop
✓ Punt = 20 yds free
✓ Possessions start at 20
✓ No official timeouts
✓ Every player carries EVERY game
✓ No playoffs — all games equal
✓ Running clock, 2 halves
✓ Safety = flag in own end zone
✓ Equal playing time for all
✓ Development over competition
Mount Prospect treats 5/6 as an instructional, in-house league. Development first. Every kid touches the ball every game.
